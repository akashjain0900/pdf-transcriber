Gemini API keys

One row per key. Quota is enforced per Google Cloud project, not per key, so keys from the same project share one allowance — only keys from separate accounts or projects add capacity. Each live key runs its own worker.

Set the daily limit from what AI Studio shows for that account. If it is too high, Ledger learns the real ceiling from repeated refusals and corrects itself. Counters reset at midnight US Pacific, which is when Google resets them.

At most 5 keys are used at a time. Ticked keys enter in the order listed; when one runs out for the day the next ticked key takes its place automatically. Rows in play are marked in play. Untick a key to take it out of rotation entirely.

Engine settings

These come from .env and are shown read-only on purpose: changing DPI or resolution mid-corpus would leave you with pages transcribed under different settings and no easy way to tell which is which. Edit .env and restart to change them.

One-time sheet setup

Only needed if you want transcriptions in Google Sheets. The JSON export works without any of this.

  1. Open sheets.google.com and create a blank spreadsheet. Transcriptions go here, one tab per book.
  2. In that sheet: Extensions → Apps Script. Delete the placeholder code.
  3. Copy the script below and paste it in, replacing everything.
  4. Optional: set SHARED_SECRET near the top to any string, then enter the same string under Sheets & Settings. Without it, anyone with your Web App URL can write to the sheet.
  5. Click Deploy → New deployment, type Web app. Set "Execute as" to Me and "Who has access" to Anyone. Deploy, then authorise it (click through the "unverified app" warning — it is your own script).
  6. Copy the Web App URL into Sheets & Settings and click Test.

If you edit the script later, use Deploy → Manage deployments → edit (pencil) → New version, otherwise the live URL keeps running the old code. The Test button reports the deployed version so a stale deployment is visible.
